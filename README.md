## 📋 Overview

**Student Skills Tracking System** is a revolutionary web-based platform designed to eliminate the gap of interaction between the Indian Government and Universities. The system maintains comprehensive data of each student using latest technology, recognizing that students are a great resource not only for India's reputation and growth but also for the economy.

### 🎯 The Problem

India lacks a unified platform where:
- Universities can track and showcase their students' technological growth
- Government can monitor the national talent pool and skill distribution
- Students can build comprehensive digital portfolios with all their achievements
- Real-time analytics on India's technological advancement are available

### 💡 Our Solution

A centralized platform that:
- **Tracks every detail** of students including university rankings, global rankings, aptitude scores, and coding statistics
- **Integrates coding platforms** like LeetCode, GeeksforGeeks, CodeChef to automatically fetch student progress
- **Provides complete portfolios** for each student showcasing skills, certifications, projects, and achievements
- **Enables government monitoring** of each student, each college, and overall technology growth in India
- **Broadcasts opportunities** including hackathons, jobs, and technology news to students

## 🚀 Installation

### Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v14.0 or higher)
- **npm** or **yarn**
- **MongoDB** (local installation or Atlas account)
- **Git**

### Step-by-Step Setup

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/student-skills-tracking-system.git
cd student-skills-tracking-system
```

#### 🚀 Quick Start (Recommended)

You can use the scripts in the root directory to set up and run both frontend and backend together:

```bash
# Install dependencies for both frontend and backend
npm run install:all

# Start both frontend and backend concurrently
npm run dev
```

#### 2️⃣ Backend Setup

```bash
# Navigate to backend directory
cd backend

# Install dependencies
npm install

# Create .env file
touch .env
```

Add the following environment variables to `.env`:

```env
# Server Configuration
PORT=5000
NODE_ENV=development

# Database
MONGODB_URI=mongodb://localhost:27017/student-tracking
# Or use MongoDB Atlas:
# MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/student-tracking

# JWT Secret
JWT_SECRET=your_super_secret_jwt_key_here
JWT_EXPIRE=30d

# Email Configuration (Optional)
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password

# Coding Platform APIs (if available)
LEETCODE_API_KEY=your_leetcode_api_key
GFG_API_KEY=your_gfg_api_key
```

```bash
# Start the backend server
npm start
# or for development with auto-reload
npm run dev
```

Backend will run on `http://localhost:5000`

#### 3️⃣ Frontend Setup

Open a new terminal:

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Create .env file
touch .env
```

Add the following to `.env`:

```env
REACT_APP_API_URL=http://localhost:5000
REACT_APP_ENV=development
```

```bash
# Start the frontend development server
npm start
```

Frontend will run on `http://localhost:3000`

#### 4️⃣ Access the Application

- **Frontend:** Open [http://localhost:3000](http://localhost:3000) in your browser
- **Backend API:** [http://localhost:5000](http://localhost:5000)
- **API Documentation:** [http://localhost:5000/api-docs](http://localhost:5000/api-docs)

## 📊 Ranking Algorithm

Students are ranked based on a weighted scoring system:

```javascript
Total Score = (Coding Score × 0.40) + 
              (Project Score × 0.25) + 
              (Certification Score × 0.15) + 
              (Activity Score × 0.10) + 
              (Aptitude Score × 0.10)

Where:
- Coding Score: Based on problems solved, difficulty, and contest ratings
- Project Score: Number and quality of projects
- Certification Score: Relevant certifications earned
- Activity Score: Active days and consistency
- Aptitude Score: Performance in aptitude tests
```
